# Dubai property prices 2026 (DLD sales data)

Area-level price pages built from Dubai Land Department open data, compiled by Certified Poor.

- `price-per-sq-ft/` – price per sq ft by area
- `villa-prices/` – villa and townhouse prices by area
- `buying-costs/` – off-plan buying costs
- `cheapest-areas/` – cheapest areas for studios and 1-bedroom apartments

Current data and downloads: https://certifiedpoor.com/open-data/
